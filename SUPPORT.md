# Support

System Atlas is an early release candidate and is not production-ready.
Community support is provided on a best-effort basis.

## Bug reports

Use the
[bug report form](https://github.com/iEssam/System-Atlas/issues/new?template=bug.yml)
for reproducible defects. Remove personal data, usernames, file paths, process
arguments, tokens, and unrelated system information from logs before attaching
them.

Include:

- System Atlas version or commit
- Windows edition, version, build, and architecture
- Installation or development launch method
- Clear reproduction steps
- Expected and actual behavior
- Relevant redacted logs or screenshots

## Feature requests

Use the
[feature request form](https://github.com/iEssam/System-Atlas/issues/new?template=feature.yml).
Describe the user problem before proposing an implementation.

## Questions

Search the [documentation](README.md) and existing
[issues](https://github.com/iEssam/System-Atlas/issues) first. If the answer is
not available, open a regular issue with enough context for someone else to
reproduce the situation.

## Security

Do not report vulnerabilities publicly. Follow the private process in
[SECURITY.md](SECURITY.md).

## Commercial support

No paid support, service-level agreement, or guaranteed response time is
currently offered.
