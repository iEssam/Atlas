# System Atlas v0.3.0-rc.1 (release candidate)

> This is the historical record for the `v0.3.0-rc.1` tag. For the current branch, see [../current-state.md](../current-state.md) and [../phases.md](../phases.md).

**Status:** Release candidate, not for production. It packages the implemented
MVP, R2, and R3 feature slices described below; it does not mark every tracker
item complete or approve the product for a stable release. The MSI is **unsigned**;
sign it before any distribution.

Windows system intelligence and control: a modern Task Manager / Process Explorer /
Process Lasso alternative built as a LocalSystem collection service (Rust) plus a
WinUI 3 desktop app (C#/.NET 10), talking over gRPC-on-named-pipes and a lock-free
shared-memory ring.

## What's in it

**Collection** — user-mode only (no kernel driver, by design; see ADR-0001):
ETW process/image events, `NtQuerySystemInformation`, SCM/services, registry &
ConsentStore watchers, Restart Manager, GPU (D3DKMT + vendor libs), battery, ACPI
thermal via WMI, and per-process security metadata.

**Storage** — SQLite (WAL) for entities/events + a custom Gorilla-compressed
time-series store with tiered T0/T1/T2 roll-ups that preserve peaks and honor
bookmark pins.

**Intelligence** — threshold+duration incident detection (CPU saturation, memory
pressure), evidence-based diagnosis with confidence-laddered contributing factors
(no LLM), and a fully redacted support bundle (paths / users / host / command lines).

**Control** — a rules engine (priority / affinity / EcoQoS) with guaranteed
reversibility, named rule profiles, and a dynamic responsiveness-protection
watchdog that dampens a runaway process and auto-restores it.

**Privacy** — camera / microphone / location usage alerts sourced from the
ConsentStore, with conditions (any-use, background, while-locked, longer-than).

**Forensics** — system-change tracking, crash correlation, and boot analysis.

**Extensibility (read-only)** — a read-only MCP server exposing grounded query
tools to your own MCP client, and a signed, capability-scoped plugin framework:
out-of-process plugins are Authenticode-verified, registered **disabled** until
explicitly enabled, and every call is scope-checked (mutations are always denied).

**Surfaces** — WinUI 3 desktop app; a dev-console/CLI; and a Windows service
(auto-start, LocalSystem, crash-restart) installed by a per-machine WiX MSI.

## Install

Per-machine MSI (elevation required; registers and starts the SystemAtlas service):

```
msiexec /i SystemAtlas-0.3.0.0-x64.msi
```

Supports clean install, in-place major upgrade, and clean removal
(`msiexec /x`). The `%ProgramData%\SystemAtlas` data directory is intentionally
preserved across uninstall so a reinstall keeps history.

## Validation

- **14/14** gated automated checks pass in an elevated, WDAC-exempt session
  (`scripts/elevated-validation.ps1`): WDAC-exempt execution, live ETW, service
  install/start/crash-restart/uninstall, incident detection + redacted bundle,
  and full plugin capability enforcement.
- Manual camera/microphone privacy trigger: confirmed live.
- MSI install/upgrade/removal lifecycle: `installer/validate-install.ps1`.

## Known limitations

- **No first-party kernel driver** (ADR-0001). CPU package temperature and
  fan/EC/voltage sensors that require a driver are unavailable and labeled
  honestly rather than faked.
- The MSI is **unsigned** — sign with a trusted cert before distribution.
- ARM64 packaging is scaffolded but not built in this RC (x64 only).
- Release candidate: APIs, schema, and the proto contract may still change before
  a stable v0.3.0.
